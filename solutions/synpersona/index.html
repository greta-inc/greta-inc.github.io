기존 고객 조사의 한계

신상품을 기획할 때 설문 조사는 비용과 시간이 많이 들고, 응답률도 계속 낮아지고 있습니다.
아직 우리 고객이 아닌 사람들의 의견은 들을 방법이 마땅치 않습니다.

그래서 내부 고객 데이터와 담당자 경험으로 페르소나를 만드는 경우가 많습니다.
다만 이렇게 만든 페르소나는 기존 고객의 특성에 치우치기 쉽습니다.

용도에 맞는 생성 엔진 3종

생성 속도, 원본과의 유사도, 개인정보 보호 수준은 서로 균형을 맞춰야 하는 요소입니다.
데이터 특성과 목적에 따라 세 가지 엔진 중 하나를 선택할 수 있습니다.

SynWeave

가볍고 빠른 모델

원본의 분포와 패턴을 잘 보존하며, 빠른 결과가 필요할 때 적합합니다.

SynForma

통계학적 모델

유사성과 안전성의 균형을 맞추며, 통계적 근거가 필요한 분석에 적합합니다.

SynVista

딥러닝 모델

Diffusion 계열 모델로, 개인정보 보호를 가장 중요하게 볼 때 적합합니다.
