이럴 때 씁니다

개인정보나 영업 비밀 때문에 원본 데이터를 그대로 쓰기 어려운 경우가 많습니다.
합성데이터는 원본의 통계적 특성은 유지하고, 실제 개인의 기록은 담지 않습니다.

외부 협업

함께 분석해야 할 때

협력사나 연구기관에 원본 대신 합성데이터를 넘겨 분석을 맡깁니다.

모델 개발

모델을 만들고 검증할 때

분석·AI 모델 개발과 검증에 쓸 데이터를 원본 반출 없이 준비합니다.

시스템 시험

서비스를 시험할 때

실제와 비슷한 분포의 데이터로 서비스와 시스템을 시험합니다.

1원본 데이터→2생성 엔진 선택→3합성데이터 생성→4품질 보고서

용도에 맞는 생성 엔진 3종

생성 속도, 원본과의 유사도, 개인정보 보호 수준은 서로 균형을 맞춰야 하는 요소입니다.
데이터 특성과 목적에 따라 세 가지 엔진 중 하나를 선택할 수 있습니다.

SynWeave

가볍고 빠른 모델

원본의 분포와 패턴을 잘 보존하며, 빠른 결과가 필요할 때 적합합니다.

SynForma

통계학적 모델

유사성과 안전성의 균형을 맞추며, 통계적 근거가 필요한 분석에 적합합니다.

SynVista

딥러닝 모델

Diffusion 계열 모델로, 개인정보 보호를 가장 중요하게 볼 때 적합합니다.
